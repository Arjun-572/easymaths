# EasyMaths

EasyMaths is an AI-powered mathematics learning chatbot designed to help students understand and solve mathematical problems step by step.

## Features

- Step-by-step mathematical solutions
- Differentiation
- Integration
- Equation solving
- Simplification
- Limits
- Mathematical explanations using AI
- Formula reference
- Course-based mathematics content
- English and Telugu language support
- User accounts and chat history
- LaTeX mathematical formatting

## Technologies Used

- Python
- FastAPI
- SymPy
- Ollama
- Qwen 2.5 3B
- SQLite
- HTML
- CSS
- JavaScript
- KaTeX
